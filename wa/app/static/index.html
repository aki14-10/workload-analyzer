Workload Design

Resource Planning

Placement rule: VMs lacking the required CPU or memory are excluded; among feasible VMs the lowest normalized load (assigned burst divided by CPU capacity) is chosen. Each VM then schedules its own queue.

Policy Analysis

Slack = deadline - estimated completion; negative slack is a predicted miss. Risk: Likely to Miss (slack below 0), At Risk (slack below the task burst), Low Risk otherwise. Rule-based categories, not probabilities. Policy changes are accepted only if predicted misses fall, or total completion improves beyond the threshold after the penalty is applied.

About Project

The Workload Analyzer: Adaptive Cloud Task Scheduler with Deadline-Risk Prediction is an Operating Systems simulation project that studies workload characteristics, CPU scheduling policies, deadline constraints, and virtual-machine resource allocation. It introduces an explainable adaptive scheduling policy that reassesses scheduling decisions using workload analysis and deadline-risk estimates. Its performance is evaluated against conventional scheduling algorithms through controlled experiments.
